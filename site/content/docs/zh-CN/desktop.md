## 对话 {#conversation}

- **两边共用一个列表。** 对话列表就是 mu 自己的会话文件。在终端里开始的会话会出现在桌面端里，在桌面端开始的会话也可以用 `mu -c` 或 `mu -r` 接着做。
- **默认安静。** mu 主动对模型说的话，比如提醒去验证、目标续跑、新出现的错误或一次回退，只显示成一行，用你的语言写；原文点一下就能看到。一串工具调用折叠成一行，说明做了什么，比如「读了 3 个文件 · 运行了 1 条命令」。
- **文件在旁边打开。** 点工具调用读过或写过的文件路径，或者回复里提到的文件，它就在工作面板的预览里打开：代码和其他文本、Markdown、HTML、PDF、CSV、图片和 diff。其他文件用它们自己的应用打开。
- **开发服务器在应用里打开。** 命令输出了本地地址（比如 `http://localhost:5173/`）时，下面会出现一个按钮，在工作面板的浏览器里打开这个页面。
- **从任意消息分叉。** 每条消息都有一个分叉按钮，从那里开一个新分支。
- **回到某条消息之前。** 你的消息那一轮改过文件的话，消息下面有一个按钮，可以回到 mu 当时存下的检查点。mu 会问你回退文件、对话还是两者都回退。对话回退时，你那条消息会回到发送框，方便重新发送。
- **每行的菜单。** 重命名、置顶、标为未读、归档或删除一个对话。

## 需要你的时候 {#attention}

- **通知。** 别的对话完成或在等你时，系统会通知你。
- **Dock 图标上的数字**显示有几个对话在等你（macOS；Linux 上是启动器图标）。
- **想要的话，还可以响一声。** 「设置 → 系统 → 会话完成或需要你时播放提示音」。即使 mu 就在前台也会响；mu 有问题要问或者运行失败时，响的是另一种提示音。打开后系统通知会静音，免得你听到两次。默认关闭。
- **对话运行时电脑不会睡眠**，长时间的运行不会被空闲睡眠打断。屏幕照样可以关，合上盖子照样会睡眠。在「设置 → 系统」里可以关掉。

## 发送框 {#send-box}

- **权限模式。** 完全访问、判定模式或最小权限，每个对话单独切换。见[权限与安全](@docs/permissions)。
- **目标。** 设定一个目标，代理就一直干到它成立。目标运行时，发送框上方的目标栏显示它的状态。见[目标模式](@docs/goal)。
- **上下文环。** 上下文用了多少，一眼看清。
- **排队的消息。** 代理干活时发出的消息会排队等待，在被用上之前可以撤回。
- **斜杠命令。** 输入 `/` 列出 mu 和 pi 的命令，和终端里一样。
- **你指给 mu 看的东西随下一条消息发出。** 页面元素、截图、页面控制台，或者对 diff 某一行的评论，会在发送框里显示成小标签，发送前都可以移除。
- **后台命令。** 有命令在后台运行时（比如开发服务器、watcher 或耗时很长的构建），发送框旁边的小标签会显示有几个。点开能看到每个命令、它运行了多久和它的日志，可以停掉其中一个或全部。对话的文件夹里有带脚本的 package.json 时，小标签会显示**运行**并列出这些脚本：点「运行」就把它作为后台任务启动，结束时 mu 会收到通知，所以你可以直接问它测试为什么失败了。在终端里，`/jobs start [--name <label>] <command>` 做的是同一件事。

## 键盘 {#keys}

Windows 和 Linux 上，把 <kbd>⌘</kbd> 换成 <kbd>Ctrl</kbd>。

| 按键 | 作用 |
| --- | --- |
| <kbd>⌘K</kbd> | 命令面板：对话、设置和命令 |
| <kbd>⌘P</kbd> | 按名字打开对话文件夹里的文件 |
| <kbd>⌘1</kbd> 到 <kbd>⌘9</kbd> | 打开侧栏里对应位置的对话 |
| <kbd>⇧⌘A</kbd> | 打开下一个在你离开时完成或提了问题的对话 |
| <kbd>Ctrl Tab</kbd>、<kbd>Ctrl ⇧ Tab</kbd> | 打开下面或上面的对话 |
| <kbd>⌘/</kbd> | 列出应用支持的所有快捷键 |

这张表也能从命令面板和「帮助 → 键盘快捷键」打开，按键按你的系统习惯显示。

## 工作面板 {#panel}

对话旁边的面板有八个标签页：

| 标签页 | 显示什么 |
| --- | --- |
| **看板** | [人话看板](@docs/board)：工作做到哪了、现在在做什么、有什么在等你，以及一份流水 |
| **判定** | 实时的流水：每一次判定，带着它的问题、答案、概率和用时 |
| **蜂群** | [蜂群](@docs/hive)：每只蜂、它在做什么，以及一张哪条发现送给了谁的图 |
| **经验** | [经验库](@docs/lessons)：mu 学到了什么、每条经验被召回和照做了多少次；可以编辑或让一条退役 |
| **文件** | 项目的文件 |
| **预览** | 正在处理的文件或页面：代码、Markdown、HTML、PDF、CSV、图片和 diff |
| **源码** | 这个文件夹的 git 改动和 diff、提交框，以及当前分支的拉取请求 |
| **浏览器** | 代理逐步操作的内置浏览器，带着它的目标；可以暂停、接管或停止 |

**面板会跟着代理走。** 面板开在文件、预览、源码或浏览器上时，代理写完的文件会显示在预览里；代理用浏览器时，浏览器标签页会切到前面。面板关着时只会出现小圆点。这几个标签页上有一个开关，可以关掉跟随。

### 源码管理 {#source}

- **暂存和提交。** 暂存或取消暂存一个文件或整个分组，写好提交说明，按 <kbd>⌘Enter</kbd> 提交。没有暂存任何东西时，「全部提交」会先暂存所有改动，包括新文件。git 拒绝时（比如 hook 失败，或者没有设置身份），它的输出会显示在提交框下面。
- **一次一处改动。** 在文件的 diff 里，每处改动都有「暂存这处改动」按钮，已暂存的 diff 里则是「取消暂存这处改动」，这样就能只提交文件的一部分。暂存从不改动磁盘上的文件。
- **让 mu 提交。** mu 把改动拆成几次提交并写好提交说明，先把方案给你看，你同意后才提交。
- **这里不会丢掉任何东西。** 这个标签页没有丢弃按钮；要把文件恢复回去，就回到某条消息之前。
- **当前分支的拉取请求。** 分支那一行下面显示拉取请求的编号和标题（点击在 GitHub 上打开）、它的状态，以及有多少项检查通过了。点击这个数字可以列出各项检查，再打开其中一项。有检查还在运行时，这一行每 30 秒刷新一次。分支还没有拉取请求时，「让 mu 创建」会让 mu 推送分支并创建一个；创建之前，mu 会先给你看标题、描述、目标仓库和目标分支。这用的是 GitHub 的 `gh` 命令行，以你的身份登录；没有它就不显示这一行。

### diff 上的评论 {#diff-comments}

在预览里的 diff 上，每一行旁边的按钮会在这一行下面打开一个评论框。你的评论随下一条消息发出，每条都带着文件、行号和那一行代码。

### 内置浏览器 {#browser}

内置浏览器用自己独立的配置目录，从不碰你自己的浏览器。每一步都显示点了什么、判定器有多确定；提交、付款或删除之前会停下来先问你。

有三个按钮可以把你看到的东西给 mu：

- **选取元素。** 点页面上的一个元素，这次点击不会传给页面。这个元素随下一条消息发出，带着页面地址、能找到它的选择器、它的文字、样式和 HTML，还附一张它的图。<kbd>↑</kbd> 选中它的父元素，<kbd>Esc</kbd> 取消。
- **截图。** 把页面现在的样子作为图片放进下一条消息。
- **控制台。** 页面加载后打印过错误或警告时，会出现一个按钮显示条数；点它会把最近 50 条放进下一条消息，从早到晚排列，每条都带着来源。

## 登录模型 {#models}

「设置 → 模型」让你不离开应用就能接入模型：用 ChatGPT 登录，或者粘贴任何 pi 支持的提供商的 API key。你自己的服务器也可以，包括本机或局域网里的普通 `http://` 地址。

Google 的这两种登录，是 Google 给自家工具用的登录。从别的程序使用它们可能违反 Google 的条款，所以桌面端会先说明风险，你同意才继续。Gemini API key 和 Vertex AI 都不涉及这些。

## 设置 {#settings}

设置按类别分组：**偏好**、**模型**、**内核**、**细项**、**能力**和**系统**。侧栏顶部的搜索框能找到任何一项设置。

- **内核**页把每个功能列成一行，带一个开关；它的判定点列在下面，每个都有自己的开关。「判定器」页决定由谁来回答。
- **能力**页按来源列出技能（mu 自带的、项目的，或沿用自 Claude Code、Codex 和 Cursor 的），可以添加一个技能文件夹、移除你自己加的；还列出 MCP 服务器，每个带一个开关。作为参数传给服务器的密钥会被遮盖。
- **系统**页里有提示音，以及运行时不让电脑睡眠的开关。
- 设置改动的一切都写进 `~/.mu/agent/mu.json`，所以对命令行同样有效，反过来也一样。

界面有 13 种语言，包括简体中文、繁体中文、英语、日语和韩语。

## 导入对话 {#import}

Claude Code、Codex CLI 和 ZCode 的对话可以连同完整历史导入 mu 并接着聊：消息、工具调用、思考过程和图片都在。新手引导发现这些对话时，会在第一屏提出导入，设置里也能导入。同一段对话再导入一次，会把之后新增的内容带过来。命令行用 `mu import --list` 和 `mu import <file>`。

## 更新、网络代理和日志 {#updates}

- **更新。** 有新版本时桌面端会告诉你，连同它的大小；你同意后才下载，下次重启时安装。
- **网络代理。** 没有设置 `HTTPS_PROXY` 时，桌面端里的 mu、各种登录和密钥检查都跟随系统代理。
- **日志。** 「设置 → 关于」可以打开日志文件夹。

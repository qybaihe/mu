## 在你的機器上 {#local}

- **金鑰只在本機。** API 金鑰和登入資訊存在 `~/.mu` 裡，每個判定器金鑰只送給它所屬的服務。金鑰從不寫進 `mu.json`；自訂判定器寫的是存放金鑰的環境變數名稱。
- **不偷偷下載。** mu 從不自己下載模型或執行環境。本機判定器、桌面版的更新，以及其他任何需要下載的東西，都會先問你。
- **快照跳過機密。** 檢查點從不收進 `.env` 檔案、私密金鑰或憑證，並且存放在只有你能讀的資料夾裡。
- **你的其他工具只讀不改。** Claude Code、Cursor 和 Codex 的規則、技能和 MCP 伺服器只會被讀取。

## 判定器能看到什麼 {#judge}

判定器只看到一個問題需要的欄位：一則訊息、一塊輸出、一條指令、一段簡短的執行摘要。任何東西到達判定器或看板之前，認證資訊都會被遮蔽。

沒有判定器金鑰時，這些欄位會送給 OpenCode Zen 上免費的 Jev（Jev 是 TypeSafe 託管的判定模型，也是預設的判定器）。OpenCode 不拿它們訓練模型，mu 每天提示一次。用你自己的金鑰時，它們會送給你選的服務。要讓一切都留在本機，就用本機判定器（`MU_JUDGE=laya`），或者關掉判定器（`mu setup --judge off`，或在 `mu setup` 問判定器時選「暫時不要」；mu 的功能照常按規則運作），或者關掉整個判定核心（`MU_JUDGE=off`）。

## 帳本 {#ledger}

每一次判定都記錄在你的機器上，存在工作階段檔案裡：結果、答案和它們的機率、耗時，以及它來自判定器還是備援。你可以用 `mu ledger` 或桌面版的「判定」頁全部翻閱。被判定的狀態本身，只有你設定了 `"recordState": true` 才會保存。

## 人話看板 {#board}

看板由你選的模型來寫。它讀的是代理自己的話和步驟，像任何別的模型呼叫一樣，送給那個模型的供應商。看板從不進入做事的模型的上下文。

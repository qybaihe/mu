## 對話 {#conversation}

- **兩邊共用一個列表。** 對話列表就是 mu 自己的工作階段檔案。在終端機裡開始的工作階段會出現在桌面版裡，在桌面版開始的工作階段也可以用 `mu -c` 或 `mu -r` 接著做。
- **預設安靜。** mu 主動對模型說的話，例如提醒去驗證、目標續跑、新出現的錯誤或一次回退，只顯示成一行，用你的語言寫；原文點一下就能看到。一串工具呼叫摺疊成一行，說明做了什麼，例如「讀了 3 個檔案 · 執行了 1 條指令」。
- **檔案在旁邊開啟。** 點工具呼叫讀過或寫過的檔案路徑，或回覆裡提到的檔案，它就在工作面板的預覽裡開啟：程式碼和其他文字、Markdown、HTML、PDF、CSV、圖片和 diff。其他檔案用它們自己的應用程式開啟。
- **開發伺服器在應用程式裡開啟。** 指令輸出了本機位址（例如 `http://localhost:5173/`）時，下面會出現一個按鈕，在工作面板的瀏覽器裡開啟這個頁面。
- **從任一則訊息分叉。** 每則訊息都有一個分叉按鈕，從那裡開出一個新分支。
- **回到某則訊息之前。** 你的訊息那一輪改過檔案的話，訊息下面有一個按鈕，可以回到 mu 當時存下的檢查點。mu 會問你要回退檔案、對話還是兩者都回退。對話回退時，你那則訊息會回到傳送框，方便重新送出。
- **每一列的選單。** 重新命名、置頂、標為未讀、歸檔或刪除一個對話。

## 需要你的時候 {#attention}

- **通知。** 別的對話完成或在等你時，系統會通知你。
- **Dock 圖示上的數字**顯示有幾個對話在等你（macOS；Linux 上是啟動器圖示）。
- **想要的話，還可以響一聲。** 「設定 → 系統 → 對話完成或需要你時播放提示音」。即使 mu 就在前景也會響；mu 有問題要問或執行失敗時，響的是另一種提示音。開啟後系統通知會靜音，免得你聽到兩次。預設關閉。
- **對話執行時電腦不會睡眠**，長時間的執行不會被閒置睡眠打斷。螢幕照樣可以關，闔上蓋子照樣會睡眠。在「設定 → 系統」裡可以關掉。

## 傳送框 {#send-box}

- **權限模式。** 完全存取、判定模式或最小權限，每個對話各自切換。請見[權限與安全](@docs/permissions)。
- **目標。** 設定一個目標，代理就一直做到它成立。目標執行時，傳送框上方的目標列顯示它的狀態。請見[目標模式](@docs/goal)。
- **上下文環。** 上下文用了多少，一眼看清。
- **排隊的訊息。** 代理做事時送出的訊息會排隊等待，在被用上之前可以收回。
- **斜線指令。** 輸入 `/` 列出 mu 和 pi 的指令，和終端機裡一樣。
- **你指給 mu 看的東西會隨下一則訊息送出。** 頁面元素、截圖、頁面主控台，或對 diff 某一行的評論，會在傳送框裡顯示成小標籤，送出前都可以移除。
- **背景指令。** 有指令在背景執行時（例如開發伺服器、watcher 或耗時很長的建置），傳送框旁邊的小標籤會顯示有幾個。點開能看到每個指令、它執行了多久和它的日誌，可以停掉其中一個或全部。對話的資料夾裡有帶指令碼的 package.json 時，小標籤會顯示**執行**並列出這些指令碼：點「執行」就把它當成背景工作啟動，結束時 mu 會收到通知，所以你可以直接問它測試為什麼失敗。在終端機裡，`/jobs start [--name <label>] <command>` 做的是同一件事。

## 鍵盤 {#keys}

Windows 和 Linux 上，把 <kbd>⌘</kbd> 換成 <kbd>Ctrl</kbd>。

| 按鍵 | 作用 |
| --- | --- |
| <kbd>⌘K</kbd> | 命令面板：對話、設定和指令 |
| <kbd>⌘P</kbd> | 依名稱開啟對話資料夾裡的檔案 |
| <kbd>⌘1</kbd> 到 <kbd>⌘9</kbd> | 開啟側欄裡對應位置的對話 |
| <kbd>⇧⌘A</kbd> | 開啟下一個在你離開時完成或提出問題的對話 |
| <kbd>Ctrl Tab</kbd>、<kbd>Ctrl ⇧ Tab</kbd> | 開啟下面或上面的對話 |
| <kbd>⌘/</kbd> | 列出應用程式支援的所有快速鍵 |

這張表也能從命令面板和「說明 → 鍵盤快速鍵」開啟，按鍵依你的系統習慣顯示。

## 工作面板 {#panel}

對話旁邊的面板有八個分頁：

| 分頁 | 顯示什麼 |
| --- | --- |
| **看板** | [人話看板](@docs/board)：工作做到哪了、現在在做什麼、有什麼在等你，以及一份流水 |
| **判定** | 即時的帳本：每一次判定，連同它的問題、答案、機率和耗時 |
| **蜂群** | [蜂群](@docs/hive)：每隻蜂、它在做什麼，以及一張哪條發現送給了誰的圖 |
| **經驗** | [經驗庫](@docs/lessons)：mu 學到了什麼、每條經驗被召回和照做了多少次；可以編輯或讓一條退役 |
| **檔案** | 專案的檔案 |
| **預覽** | 正在處理的檔案或頁面：程式碼、Markdown、HTML、PDF、CSV、圖片和 diff |
| **原始碼** | 這個資料夾的 git 變更和 diff、提交框，以及目前分支的拉取請求 |
| **瀏覽器** | 代理逐步操作的內建瀏覽器，連同它的目標；可以暫停、接手或停止 |

**面板會跟著代理走。** 面板開在檔案、預覽、原始碼或瀏覽器上時，代理寫完的檔案會顯示在預覽裡；代理使用瀏覽器時，瀏覽器分頁會切到前面。面板關著時只會出現小圓點。這幾個分頁上有一個開關，可以關掉跟隨。

### 原始碼管理 {#source}

- **暫存和提交。** 暫存或取消暫存一個檔案或整個分組，寫好提交說明，按 <kbd>⌘Enter</kbd> 提交。沒有暫存任何東西時，「全部提交」會先暫存所有變更，包括新檔案。git 拒絕時（例如 hook 失敗，或沒有設定身分），它的輸出會顯示在提交框下面。
- **一次一處變更。** 在檔案的 diff 裡，每處變更都有「暫存這處變更」按鈕，已暫存的 diff 裡則是「取消暫存這處變更」，這樣就能只提交檔案的一部分。暫存從不改動磁碟上的檔案。
- **讓 mu 提交。** mu 把變更拆成幾次提交並寫好提交說明，先把方案給你看，你同意後才提交。
- **這裡不會丟掉任何東西。** 這個分頁沒有捨棄按鈕；要把檔案還原，就回到某則訊息之前。
- **目前分支的拉取請求。** 分支那一行下面顯示拉取請求的編號和標題（點擊在 GitHub 上開啟）、它的狀態，以及有多少項檢查通過了。點擊這個數字可以列出各項檢查，再開啟其中一項。有檢查還在執行時，這一行每 30 秒更新一次。分支還沒有拉取請求時，「讓 mu 建立」會讓 mu 推送分支並建立一個；建立之前，mu 會先給你看標題、描述、目標儲存庫和目標分支。這用的是 GitHub 的 `gh` 命令列工具，以你的身分登入；沒有它就不顯示這一行。

### diff 上的評論 {#diff-comments}

在預覽裡的 diff 上，每一行旁邊的按鈕會在這一行下面開啟一個評論框。你的評論隨下一則訊息送出，每則都帶著檔案、行號和那一行程式碼。

### 內建瀏覽器 {#browser}

內建瀏覽器使用自己獨立的設定檔，從不碰你自己的瀏覽器。每一步都顯示點了什麼、判定器有多確定；送出、付款或刪除之前會停下來先問你。

有三個按鈕可以把你看到的東西給 mu：

- **選取元素。** 點頁面上的一個元素，這次點擊不會傳給頁面。這個元素隨下一則訊息送出，帶著頁面位址、能找到它的選取器、它的文字、樣式和 HTML，還附一張它的圖。<kbd>↑</kbd> 選取它的父元素，<kbd>Esc</kbd> 取消。
- **截圖。** 把頁面現在的樣子當成圖片放進下一則訊息。
- **主控台。** 頁面載入後印出過錯誤或警告時，會出現一個按鈕顯示筆數；點它會把最近 50 筆放進下一則訊息，從早到晚排列，每筆都帶著來源。

## 登入模型 {#models}

「設定 → 模型」讓你不離開應用程式就能接上模型：用 ChatGPT 登入，或者貼上任何 pi 支援的供應商的 API 金鑰。你自己的伺服器也可以，包括本機或區域網路裡一般的 `http://` 位址。

Google 的這兩種登入，是 Google 給自家工具用的登入方式。從別的程式使用它們可能違反 Google 的條款，所以桌面版會先說明風險，你同意才繼續。Gemini API 金鑰和 Vertex AI 都不涉及這些。

## 設定 {#settings}

設定依類別分組：**偏好**、**模型**、**核心**、**細項**、**能力**和**系統**。側欄頂端的搜尋框能找到任何一項設定。

- **核心**頁把每個功能列成一行，附一個開關；它的判定點列在下面，每個都有自己的開關。「判定器」頁決定由誰來回答。
- **能力**頁依來源列出技能（mu 內建的、專案的，或沿用自 Claude Code、Codex 和 Cursor 的），可以新增一個技能資料夾、移除你自己加的；還列出 MCP 伺服器，每個附一個開關。作為參數傳給伺服器的金鑰會被遮蔽。
- **系統**頁裡有提示音，以及執行時不讓電腦睡眠的開關。
- 設定改動的一切都寫進 `~/.mu/agent/mu.json`，所以對命令列同樣有效，反過來也一樣。

介面有 13 種語言，包括簡體中文、繁體中文、英文、日文和韓文。

## 匯入對話 {#import}

Claude Code、Codex CLI 和 ZCode 的對話可以連同完整歷史匯入 mu 並接著聊：訊息、工具呼叫、思考過程和圖片都在。新手引導發現這些對話時，會在第一個畫面提議匯入，設定裡也能匯入。同一段對話再匯入一次，會把之後新增的內容帶過來。命令列用 `mu import --list` 和 `mu import <file>`。

## 更新、網路代理和日誌 {#updates}

- **更新。** 有新版本時桌面版會告訴你，連同它的大小；你同意後才下載，下次重新啟動時安裝。
- **網路代理。** 沒有設定 `HTTPS_PROXY` 時，桌面版裡的 mu、各種登入和金鑰檢查都跟隨系統代理。
- **日誌。** 「設定 → 關於」可以開啟日誌資料夾。

## 여러분의 컴퓨터에서 {#local}

- **키는 로컬에 남아요.** API 키와 로그인 정보는 `~/.mu`에 보관되고, 판정기 키는 각각 자기 서비스로만 보내져요. 키는 절대 `mu.json`에 들어가지 않아요. 직접 만든 판정기는 키를 담은 환경 변수의 이름을 적어요.
- **몰래 내려받지 않아요.** mu는 모델이나 런타임을 스스로 내려받지 않아요. 로컬 판정기, 데스크톱 앱의 업데이트, 그 밖에 내려받아야 하는 것은 모두 먼저 물어봐요.
- **스냅샷은 비밀을 건너뛰어요.** 체크포인트는 `.env` 파일, 개인 키, 인증서를 절대 담지 않고, 여러분만 읽을 수 있는 폴더에 있어요.
- **다른 도구는 읽기만 하고 바꾸지 않아요.** Claude Code, Cursor, Codex의 규칙, 스킬, MCP 서버는 읽기만 해요.

## 판정기가 보는 것 {#judge}

판정기는 질문 하나에 필요한 필드만 봐요. 메시지 하나, 출력 청크 하나, 명령 하나, 실행의 짧은 요약 같은 것이요. 자격 증명은 판정기나 보드에 닿기 전에 가려져요.

판정기 키가 없으면 이 필드는 OpenCode Zen의 무료 Jev(TypeSafe가 호스팅하는 기본 판정 모델)로 가요. OpenCode는 이것을 모델 학습에 쓰지 않고, mu가 하루에 한 번 그 사실을 알려 줘요. 직접 가진 키를 쓰면 여러분이 고른 서비스로 가요. 모든 것을 여러분의 컴퓨터에 두려면 Mac에서 [mude 1.0](@docs/judges#mude)만 쓰거나(`mu judge mude enable --local-only`), 로컬 판정기 Laya(`MU_JUDGE=laya`)를 쓰거나, 판정기를 끄거나(`mu setup --judge off`, 또는 `mu setup`에서 판정기를 "Not now"로 고르기. mu의 기능은 규칙대로 계속 동작해요), 커널 전체를 끄세요(`MU_JUDGE=off`).

## 판정 장부 {#ledger}

모든 판정은 여러분의 컴퓨터, 세션 파일에 기록돼요. 결과, 답과 그 확률, 걸린 시간, 판정기에서 나왔는지 폴백에서 나왔는지요. 전부 `mu ledger`나 앱의 판정 탭에서 읽을 수 있어요. 판정한 상태 자체는 `"recordState": true`로 설정했을 때만 남아요.

## 쉬운 말 보드 {#board}

보드는 여러분이 고른 모델이 써요. 그 모델이 읽는 것은 에이전트 자신의 말과 단계이고, 다른 모델 호출과 마찬가지로 그 모델의 프로바이더로 보내져요. 보드는 일하는 모델의 컨텍스트에 절대 들어가지 않아요.

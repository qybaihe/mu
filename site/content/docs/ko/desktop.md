## 대화 {#conversation}

- **목록 하나를 함께 써요.** 대화 목록은 mu 자체의 세션 파일이에요. 터미널에서 시작한 세션이 앱에 보이고, 앱에서 시작한 세션은 `mu -c`나 `mu -r`로 이어 갈 수 있어요.
- **기본적으로 조용해요.** mu가 스스로 모델에게 하는 말(검증하라는 알림, 목표 이어 가기, 새 오류, 되돌리기 등)은 여러분의 언어로 된 한 줄로 보이고, 원문은 한 번 클릭하면 볼 수 있어요. 연달아 실행된 도구 호출은 무엇을 했는지 알려 주는 한 줄로 접혀요. 예: *파일 3개 읽음 · 명령 1개 실행*.
- **어느 메시지에서든 분기.** 메시지마다 분기 버튼이 있어서, 그 지점부터 새 브랜치를 시작해요.
- **행 메뉴.** 대화의 이름 바꾸기, 고정, 읽지 않음으로 표시, 보관, 삭제.
- **알림.** 다른 대화가 끝나거나 여러분을 기다리면 시스템이 알려 줘요.

## 입력창 {#send-box}

- **권한 모드.** 전체 접근, *판정 모드*, 최소 권한 중 하나를 대화마다 바꿔요. [권한과 안전](@docs/permissions)을 보세요.
- **목표.** 목표를 정하면 그 조건이 충족될 때까지 에이전트가 계속 일해요. 목표가 진행되는 동안 입력창 위의 목표 줄이 그 상태를 보여 줘요. [목표 모드](@docs/goal)를 보세요.
- **컨텍스트 링.** 컨텍스트가 얼마나 찼는지 한눈에 보여 줘요.
- **대기 중인 메시지.** 에이전트가 일하는 중에 보낸 메시지는 대기열에서 기다리고, 쓰이기 전에 다시 거둘 수 있어요.
- **슬래시 명령어.** `/`를 입력하면 터미널에서와 같은 mu와 pi의 명령어가 나와요.

<kbd>⌘K</kbd>(Windows와 Linux에서는 <kbd>Ctrl K</kbd>)로 명령어 팔레트를 열어요.

## 작업 패널 {#panel}

대화 옆 패널에는 탭이 8개 있어요.

| 탭 | 보여 주는 것 |
| --- | --- |
| **보드** | [쉬운 말 보드](@docs/board): 일이 어디까지 왔는지, 지금 무슨 일이 있는지, 무엇이 여러분을 기다리는지, 그리고 이어지는 진행 기록 |
| **판정** | 실시간 판정 장부: 모든 판정과 그 질문, 답, 확률, 걸린 시간 |
| **하이브** | [하이브](@docs/hive): 비 하나하나, 각자 하는 일, 어떤 발견이 누구에게 갔는지 보여 주는 지도 |
| **교훈** | [교훈 라이브러리](@docs/lessons): mu가 배운 것, 교훈마다 몇 번 불려 나오고 지켜졌는지. 교훈을 편집하거나 사용 중지할 수 있어요 |
| **파일** | 프로젝트의 파일 |
| **미리보기** | 작업 중인 페이지나 파일의 미리보기 |
| **소스** | 폴더의 git 변경 사항과 그 diff |
| **브라우저** | 에이전트가 한 단계씩 조작하는 내장 브라우저와 그 목표. 일시 정지하거나, 직접 조작하거나, 중지할 수 있어요 |

내장 브라우저는 자체 프로필을 쓰고, 여러분의 브라우저에는 절대 손대지 않아요. 단계마다 무엇을 클릭했는지, 판정기가 얼마나 확신했는지 보여 줘요. 제출, 결제, 삭제 전에는 멈추고 먼저 물어요.

## 모델 로그인 {#models}

설정 → 모델에서 앱을 떠나지 않고 모델을 연결해요. ChatGPT로 로그인하거나, pi가 지원하는 어떤 프로바이더의 API 키든 붙여 넣을 수 있어요. 직접 운영하는 서버도 되고, 여러분의 컴퓨터나 네트워크에 있는 평범한 `http://` 주소도 돼요.

Google의 두 로그인은 Google이 자사 도구용으로 만든 로그인이에요. 다른 프로그램에서 쓰면 Google의 약관을 어길 수 있어서, 앱이 먼저 그 위험을 알리고 여러분이 동의할 때만 진행해요. Gemini API 키와 Vertex AI는 이런 절차가 필요 없어요.

## 설정 {#settings}

설정은 영역별로 묶여 있어요: **환경설정**, **모델**, **커널**, **세부 항목**, **능력**, **시스템**. 사이드바 맨 위의 검색창으로 어떤 설정이든 찾을 수 있어요.

- **커널**에는 기능 하나가 스위치와 함께 한 줄로 나와요. 그 아래에 해당 판정 지점들이 각자 스위치와 함께 있어요. 판정기 페이지에서는 누가 답할지 골라요.
- **능력**에는 스킬이 출처별로 나와요(mu의 것, 프로젝트의 것, 또는 Claude Code, Codex, Cursor에서 물려받은 것). 스킬 폴더를 추가하거나 직접 추가한 것을 지울 수 있어요. MCP 서버도 여기 나오고, 서버마다 스위치가 있어요. 서버에 인수로 넘기는 키는 가려져요.
- 설정에서 바꾼 것은 모두 `~/.mu/agent/mu.json`에 써지기 때문에 명령줄에도 그대로 적용되고, 반대도 마찬가지예요.

인터페이스는 간체 중국어, 번체 중국어, 영어, 일본어, 한국어를 포함해 13개 언어로 나와요.

## 대화 가져오기 {#import}

Claude Code, Codex CLI, ZCode의 대화는 메시지, 도구 호출, 생각, 이미지까지 기록 전체를 가져와서 mu에서 이어 갈 수 있어요. 설정 가이드는 그런 대화를 찾으면 첫 화면에서 가져오기를 제안하고, 설정에서도 할 수 있어요. 같은 대화를 다시 가져오면 그 뒤에 새로 생긴 내용이 더해져요. 명령줄에서는 `mu import --list`와 `mu import <file>`로 해요.

## 업데이트, 프록시, 로그 {#updates}

- **업데이트.** 새 릴리스가 나오면 앱이 그 크기와 함께 알려 줘요. 여러분이 동의한 뒤에만 내려받고, 다음에 다시 시작할 때 설치해요.
- **프록시.** `HTTPS_PROXY`가 설정되어 있지 않으면, 앱 안의 mu, 로그인, 키 확인이 시스템 프록시를 따라요.
- **로그.** 설정 → 정보에서 로그 폴더를 열어요.

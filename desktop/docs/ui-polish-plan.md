# mu 桌面端打磨计划（2026-10）

范围：设置页、对话运行时、首次引导。依据：2026-10-06 在开发版（原生模式、深色、简体中文、1533×1029）上逐页截图审查，并对照代码核实。

## 0. 原则

1. **设置里的每一项都要对 mu 起作用。** 在原生模式（默认）下，mu 不读的设置要么接到 mu 上，要么不出现。
2. **一处一事。** 同一件事只在一个地方开关，且只有一种控件。
3. **看得懂。** 界面里出现的每句话都用用户的语言；mu 内部给模型的话，不冒充助手的回答。
4. **短页、分组。** 侧栏分组，每页不超过 12 行，选项多就拆页，不折叠“高级”。这条沿用用户 2026-09-23 的要求。
5. **品牌。** 黑白为主，淡粉/淡紫只用于小面积点缀。首页保留大 μ 背景，左上角保留应用图标。

## 2. 设计

### 2.1 设置的新结构

侧栏从 28 项减到 23 项，不再有重复：

```text
偏好      外观 · 系统 · 对话
模型      提供商 · 默认模型 · 人话模型
内核      判定器 · 判定顺序 · 核心功能
细项      输入 · 上下文 · 经验库 · 工具 · 安全 · 回合 · 协作 · 其他
能力      技能 · MCP 服务器 · 应用内浏览器
系统      已归档的对话 · 开发者 · 关于
```

- **细项页（解决 S2）：** 每个功能一行，带一个总开关和“选项”。属于这个功能的判定点缩进列在它下面，开关文案是“让 Jev 判断”。功能关闭时，下面的判定点变灰并注明“功能已关闭”。按 manifest 中判定点的 `feature` 字段归属，38 个判定点都有归属。原来的“工具与安全”拆成“工具”（浏览器、批量判定、文件定位、语言服务器、能力包）和“安全”（危险命令、硬约束、注入筛查、权限模式），每页仍不超过 12 行。
- **核心功能：** 六个常用功能（人话看板、目标模式、子代理、蜂群、经验库、过期结果遗忘）各占一行：开关加“详细设置 ›”，后者跳到它所在细项页的那一行。只是捷径，不是第二套开关。
- **判定器（解决 S3、S4）：** 顶部是“判定生效”（全局的 active/off，原“默认模式”）。下面选判定器。服务说明只出现一次。判定模型 id 和层级顺序移到“判定顺序”页。
- **开发者（解决 S5）：** DevTools、调试端口、MCP 片段从“系统”页移过来。
- **技能 / MCP 服务器（解决 S1）：** 只显示 mu 实际加载的东西，并标出来源：mu 自己的、项目里的、从 Claude Code / Codex / Cursor 继承的。添加时写入 mu 的配置（技能放进 `~/.mu/agent/skills`，MCP 写入 mu 的 MCP 配置，与 `mu mcp add` 相同）。数据由 native host 向 harness 查询，不再走 AionCore。
- **助手页、图像生成开关：** 原生模式下 mu 不用。计划在原生模式下隐藏，经典模式不变，代码保留，可以恢复。
- **统一（解决 S6–S9）：** 开关一律用 Switch，不再用 关闭/开启 分段控件。单位只写在输入框后缀里。说明压到一行，多出的内容放进“了解更多”。“对新会话生效”只在保存条里说一次。搜索框放在侧栏顶部，搜全部设置。

### 2.2 运行时

- **R1 内核提醒：** 每种 customType 渲染成一行灰色的系统注记，用当前语言说明 mu 做了什么。例如“mu 提醒模型：改了 pelican-bike.html 但还没运行过，请它先验证”。点开可以看到发给模型的原文。不认识的 customType 也按注记处理，不当成正文。
- **R2 步骤组摘要：** “读了 3 个文件 · 跑了 1 条命令 · 改了 1 个文件”，按工具种类计数。
- **R3 路径：** 项目内显示相对路径，家目录显示成 `~`，悬停显示完整路径。
- **R4 输入框：** 首页和对话页用同一个布局：左边是附件和权限，右边是模型和发送按钮。占位提示同一句。
- **R5 默认模型：** 新会话用默认模型。用户在输入框里换了模型，只影响这个会话；输入框里提供“设为默认”。
- **R6 模型名：** 统一用显示名，id 放在悬停提示里。
- **R7–R11：** 空闲时不显示状态，运行中显示阶段；重连按钮加文字提示。“原生”分组改叫“对话”。右侧面板常驻 看板、判定、文件 三个标签，蜂群、经验、浏览器、预览、源码只在本会话用到时出现，其余收进“更多”。蜂群角色名翻译。消息导航线加悬停提示。

### 2.3 引导

新流程：欢迎 → 模型 → 权限方式 → 判定器 → 导入（只在检测到 Claude Code / Codex 对话时出现）→ 开始。

- **模型：** 检测已有的登录和密钥，显示“已连接：ChatGPT（订阅）”，可以直接下一步。
- **权限方式：** 三张卡片，每张一句话说明，默认“Jev 审批”。
- **判定器：** 显示“免费的 Jev 已就绪，不用做任何事”。自己的密钥和本地 Laya 收进“换一个”。
- **开始：** 选一个文件夹，给三个示例任务，提示 ⌘K、`/`、`@`。
- **首次提示：** 第一次出现 Jev 判定行、第一次打开右侧面板时，各显示一次一句话的说明，可以关掉。

## 4. 不做的事

- 不重画整套视觉，不改品牌色和首页的大 μ。
- 不删除 AionUi 的源码，只在原生模式下不展示 mu 用不到的页面。
- 不为截图伪造数据；验收用真实会话的副本。

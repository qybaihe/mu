# Upstream names

The desktop app began as a fork of [AionUi](https://github.com/iOfficeAI/AionUi), and AionCore, the local service it starts, began as AionUi's backend. The app's own names are mu's: the text it shows in its 13 languages, its code, its environment variables (`MU_…`), its classes, events, globals and storage keys. The old names are left only where something outside the app's code depends on them.

| Where                                                                                                                                               | What                                                                                                                                                                                                                                                                                                                   | Why                                                                                                                                          |
| --------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `packages/desktop/src/common/platform/legacyNames.ts`                                                                                               | What earlier versions wrote to people's machines: the data folder, a development build's profile and shortcuts, the config files, the browser's session partition, the built-in MCP servers' record names. And the old storage keys, CSS classes, background markers and image settings, which are moved to mu's names | Renaming them would lose or break what people already have: stored paths point into the data folder, and conversations keep the server names |
| `packages/desktop/src/common/platform/backendNames.ts`, `packages/web-host/src/backend-launcher.ts`                                                | AionCore's database file, request header, conversation source, Butler id and upload suffix; the prefix of its error codes and its ownership name; the environment variables it reads                                                                                                                                   | AionCore is a separate program and uses these names. The app speaks them only there and turns AionCore's answers into mu's names             |
| `packages/desktop/src/common/kyrn/displayName.ts`                                                                                                   | The filter that shows text arriving at run time (from AionCore, an agent, an upstream string) with mu's name                                                                                                                                                                                                           | It has to know the old names to replace them                                                                                                 |
| `packages/desktop/src/process/services/database/migrations.ts`                                                                                      | The SQL that moves the first versions' database                                                                                                                                                                                                                                                                        | It reads what those versions wrote                                                                                                           |
| `resources/windows/*.nsh`, `scripts/build-with-builder.js`                                                                                          | The installer's names for what an older installer left (`MU_LEGACY_…`, `LEGACY_NSIS_…`)                                                                                                                                                                                                                                | An update still finds it                                                                                                                     |
| Scripts that run AionCore themselves (`packages/shared-scripts/src/prepare-backend.js`, `scripts/kyrn/registration-check/`), and test fixtures     | AionCore's variables, payloads and records; what an earlier version stored                                                                                                                                                                                                                                             | That is what they run or test                                                                                                                |
| `NOTICE`, `LICENSE-APACHE`, `AIONUI-FILES.txt` (made by `scripts/aionuiFiles.mjs`), the license headers of the files it lists, the readme's credits | AionUi's copyright and license                                                                                                                                                                                                                                                                                         | The Apache License 2.0 requires them                                                                                                         |

AionCore's id for its built-in agent is `BUILTIN_AGENT` in `backendNames.ts`, the one place it is spelled out; the app's folders, components, test ids and translation keys call it the built-in agent. Names an extension uses keep AionCore's spelling too: the extension manifest `aion-extension.json` with its `engines.aionui`, and the `aion:` messages between the app and an extension's settings page.

## The words in text

| Upstream word             | In the app's own copy | In text that arrives at run time (`showAsMu`) |
| ------------------------- | --------------------- | --------------------------------------------- |
| AionUi, AionUI            | mu                    | mu                                            |
| AionCore                  | the local service     | mu                                            |
| Aion CLI, AionCLI, Aionrs | the built-in agent    | mu                                            |

## Guards

- `tests/unit/i18n/noAionWords.test.ts` fails when a locale value in any of the 13 languages, or a string in the main-process files that build the window, tray, menus, notifications and dialogs, contains `aion`, except AionCore's resource folder.
- `tests/unit/kyrn/displayName.test.ts` covers what `showAsMu` rewrites and what it leaves alone.
- `tests/unit/common-config/legacyNames.dom.test.ts` checks that the old storage keys move to keys the renderer reads, and that the theme saved under an old key is still painted before the renderer starts.
